# Group E: 管理コンソール・永続時計とテレポート（E49/E50追補）

2026-10-21。既存の積み上げPR #61 → #69 → #73 をベースにした差分。

## 追加した内容

- 管理操作はOS標準入力に限定。ログインしたユーザー名は権限に使用しない。
- `/time set <0..23999>` は昼夜時刻だけを更新（WorldAgeは維持）、直ちにオンラインプレイヤーにProtocol 5 S03を配信。
- `/weather set auto|clear|rain|thunder` は既存の天候シミュレーションを一時的に上書きし、S2Bをブロードキャスト。
- `/tp 名前 X Y Z` は操作を対象セッションの有界キューに委譲し、セッションスレッドが位置ファイルの保存・チャンク更新・S08・他プレイヤー視界更新を順番に行う。NaN、Infinity、ワールド範囲外は拒否。これによりHubだけ位置が変わり実体は変わらない不整合を避ける。
- `IRT1` 20-byte時計スナップショットは読み込み継続。新規 `IRT2` はticks+offset+weather overrideと補数を格納し、サーバ再起動後も管理変更を復元。不正/部分データは起動を失敗させる。
- 移行、改ざん、入力検証、オフラインプレイヤー、セッション間イベントの単体テストを追加。
