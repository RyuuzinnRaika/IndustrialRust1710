# E42: 無改造 Minecraft Java 1.7.10 実クライアント受入試験

状態: **手順と記録方法のみ準備済み・実機未検証**。Rust製 Protocol 5 TCPテスト（E41）はこの項目の代替にならない。

## 目的と禁止事項

1. 公式Minecraft Launcherで「リリース 1.7.10」を起動し、Forge / Fabric / OptiFine / Mod / プロキシ改変のないJava Editionクライアントを使用する。Javaや公式クライアントの著作物はリポジトリに同梱しない。
2. まずローカルPCで検証する。現在のサーバーはオフライン名＋ホワイトリストだけであり、Mojang/Microsoftのログイン本人確認を実施しない。**インターネットへポート25565を公開しない**。2台試験は信頼できるLAN内とファイアウォール制限下で行う。
3. 本試験はゲームプレイ・描画・GUI・操作・再接続を実際に確認して初めて合格とする。シミュレータのテスト結果だけで「Minecraft対応完了」と認定しない。

## セットアップ

以下はリポジトリ直下から実行する。試験用の新規保存先を使い、普段利用するセーブデータは指定しない。

```bash
cargo build --release -p vanilla-server
mkdir -p e42-test/world
```

`e42-test/whitelist.json` の例。実機クライアントの表示名に変更する。

```json
[
  {"name": "ClientA"},
  {"name": "ClientB"}
]
```

```bash
./target/release/vanilla-server --bind 127.0.0.1:25565 --whitelist ./e42-test/whitelist.json --world ./e42-test/world/test.irw --survival
```

Windowsの場合は `./target/release/vanilla-server` を `.\\target\\release\\vanilla-server.exe` に置き換える。別PCからの接続試験時に限り、OSのファイアウォールで試験端末の送信元だけを許可し、必要なら `--bind <LAN-IP>:25565` を用いる。ゲームのマルチプレイ画面でこのアドレスを指定する。

## 受入結果の機械検証（E42、2026-10-23追加）

本家クライアントのプレイ操作と目視確認は人間が実施し、結果の再現可能性と証跡の有無だけを以下のCLIで検証する。CIの単体テストは本家ゲームを実行しないため**これだけでE42をPASSにはしない**。

まずサーバーの40桁コミットSHA（`git rev-parse HEAD`）を用いて**新しい**未実行の記録を生成する。

```bash
python3 tools/e42_acceptance.py init \
  --commit "$(git rev-parse HEAD)" \
  --output ./e42-test/acceptance.json
```

`acceptance.json` の `launcher`、`os_java_runtime`、タイムゾーン付き `executed_at`、`connected_clients_peak`、マスク済みサーバー起動引数を埋める。各 `42-01`〜`42-09` に、実施した場合だけ `status: PASS`、画面で確認した `observation`、相対パスの `evidence`（ログ/画像/録画）を記録する。証跡ファイルは指定したルートの中に配置し、秘密情報を必ず削除・マスクする。

```bash
python3 tools/e42_acceptance.py verify \
  --report ./e42-test/acceptance.json \
  --evidence-root ./e42-test \
  --require-pass
```

この最終ゲートでは9ケースすべてがPASSで、各観察記録と空でないローカル証跡が存在し、複数人試験は2人以上のクライアントが接続されていたと記録されている場合だけ終了コード0になる。FAIL/BLOCKED/NOT_RUNは合格へ変換しない。検証器は添付ログや録画の真偽、操作内容の妥当性を自動判定できないため、最終承認は実機を操作した検証者が行う。
