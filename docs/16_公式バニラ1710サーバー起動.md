# Minecraft Java 1.7.10 ― Modなしで普通に遊べる公式サーバー

## まず結論

**現時点で通常のMinecraft 1.7.10を遊びたい場合は、Mojang公式のバニラサーバーJARを使用してください。** IndustrialRust1710のRust製`vanilla-server`はまだ実験用で、Survival・Mob・インベントリ・クラフト・レッドストーン・ネザー・エンド等の通常プレイを完全には実装していません。

この起動経路では、公式1.7.10のサバイバル・クリエイティブ・Mob・クラフト・レッドストーン・次元・保存・マルチプレイの機能を**公式サーバー側**で提供します。**Rustにそれらが移植されたという意味ではありません。** Mod/Forgeは不要です。

公式バイナリはMojangのサーバーからユーザーのPCへ直接取得します。リポジトリへのJAR・ワールド・アカウント情報の再配布は行いません。

## 必要なもの

- Minecraft Java Edition 1.7.10を起動できる**正規のJava Editionアカウント**とクライアント
- **Java 8** のランタイム（Java 17や最新JavaだけではなくJava 8を指定する。セキュリティ更新を適用した配布版を使用する）
- **Python 3.8以降**、インターネット接続（初回公式JARを取得）
- 推奨メモリ: 2〜4 GB（必要量はプレイヤー数や設定による）

## Windows 11 での起動

リポジトリのルートでPowerShellを開き、次を実行します。

```powershell
git pull
py -3 tools/vanilla1710.py prepare
```

初回はMojang公式の `minecraft_server.1.7.10.jar` を取得し、次のファイルを`runtime/vanilla-1.7.10/`以下に作ります。

- `minecraft_server.1.7.10.jar` — Mojang公式本体（SHA-1検証済み）
- `server.properties` — サバイバル、オンライン認証、ホワイトリスト有効、初期待受127.0.0.1:25565
- `whitelist.json` — 初期値`[]`、誰も無条件で許可しない
- `eula.txt` — **初期値 eula=false**。ユーザーが同意するまでは起動不可
- `log4j2_17-111.xml` — **Mojang公式の旧Log4j脆弱性対策**。SHA-1 `dd2b723346a8dcd48e7f4d245f6bf09e98db9696`。起動時にJVMの`-Dlog4j.configurationFile=log4j2_17-111.xml`を強制

**EULA**: [Minecraft EULA](https://www.minecraft.net/en-us/eula)を読み、自分で同意する場合のみ以下を行います。

```powershell
notepad runtime/vanilla-1.7.10/eula.txt
# eula=false を eula=true に自分で書き換えて保存
```

Java 8が`JAVA_HOME`に設定されている場合、次で起動します。

```powershell
py -3 tools/vanilla1710.py run --memory 2G
```

Java 8を別途インストールした場合は`--java`に`java.exe`を指定します。例:

```powershell
py -3 tools/vanilla1710.py run --java "C:\Path\To\Java8\bin\java.exe" --memory 2G
```

サーバーコンソールに次を入力します。**ゲーム内ではなくサーバーコンソールなので先頭のスラッシュは不要**です。

```text
whitelist add 自分のMinecraftプレイヤー名
whitelist list
```

起動後、Minecraftランチャーで**Java Edition 1.7.10（Forgeなし）**を選び、「マルチプレイ」→「ダイレクト接続」で`127.0.0.1:25565`を指定してください。

安全に終了する場合はサーバーコンソールに`stop`を入力します。

```text
save-all
stop
```

## Linux/Ubuntu

Java 8とPython 3が導入されている状態で、リポジトリのルートから:

```bash
python3 tools/vanilla1710.py prepare
nano runtime/vanilla-1.7.10/eula.txt
# Minecraft EULAに同意する場合のみ、eula=true に変更
python3 tools/vanilla1710.py run --memory 2G
```

`java -version`でJava 8（`1.8.*`）であることを確認してください。Java 8が`PATH`上にない場合、`--java /path/to/java8/bin/java`で指定できます。Java 8を使用するのはこの公式1.7.10バニラサーバー用で、Rust開発にJavaを要求するものではありません。

## LAN上の他のPCを参加させる場合

`prepare`時に明示的にLAN待受を指定します。**必ず新規の作業フォルダーを使ってください**（既存設定ファイルは保護され自動上書きされません）。

```powershell
py -3 tools/vanilla1710.py prepare --dir runtime/vanilla-1.7.10-lan --bind 0.0.0.0 --port 25565
# 別のeula.txtを確認・同意してから:
py -3 tools/vanilla1710.py run --dir runtime/vanilla-1.7.10-lan --memory 2G
```

- Windows Defender Firewall等で**プライベートネットワークのTCP 25565のみ**許可し、信頼できるLAN・VPN以外からの着信を遮断します。ルーターのポート開放やインターネットへの公開は安易に行わないでください。
- 別端末のクライアントはサーバーPCのLAN IP（例: `192.168.11.x:25565`。これは単なる例）を指定します。
- `online-mode=true`による公式アカウント認証と`white-list=true`を保持します。`online-mode=false`での名前偽装は認めません。
- `whitelist add プレイヤー名`をサーバーコンソールで実行して、参加者を明示的に許可してください。管理権限は不要なら付与しないでください。

## 古い1.7.10固有のセキュリティ対策

Minecraft 1.7.10の公式Javaサーバーは古いLog4jライブラリの脆弱性（CVE-2021-44228等）の影響を受ける可能性があります。[Mojang公式セキュリティ告知](https://www.minecraft.net/ja-jp/article/important-message--security-vulnerability-java-edition-jp)は**1.7〜1.11.2のサーバー**に専用の`log4j2_17-111.xml`を配置し、起動時に`-Dlog4j.configurationFile=log4j2_17-111.xml`を追加するよう指定しています。

このツールでは**このXMLの正当性をSHA-1で検証できなければ起動しません**。利用者はLog4j設定を手動で削除したり無効化しないでください。それでも古いソフトウェアに未知のセキュリティ問題が残る可能性があるため、公開インターネットには接続せず、信頼できるLAN/VPNに限ることを推奨します。

## 仕組み・テスト・運用

```bash
python3 tools/vanilla1710.py check
python3 -m unittest discover -s tests -p 'test_vanilla1710_launcher.py' -v
```

`check`はEULA設定、オンライン認証、ホワイトリスト、JARとLog4j脆弱性対策XMLのサイズ・SHA-1を検査します。初回の`prepare`は冪等であり、すでに存在する`server.properties`や`eula.txt`を上書きしません。異常な`online-mode`設定等は起動を拒否します。

Mojang公式1.7.10 JARの固定SHA-1: `952438ac4e01b4d115c5fc38f891710c4941df29`。固定サイズ: 9,605,030 bytes。配布元はMojang管理ドメインのみ。ネットワークが遮断されたり公式ダウンロードが停止された場合、未検証の第三者サイトからJARを自動入手しません。

`runtime/`配下はGitの追跡対象外。バックアップは**サーバーを`stop`で終了**させた後に、`runtime/vanilla-1.7.10/world/`と設定/許可リストを安全な場所へコピーしてください。
