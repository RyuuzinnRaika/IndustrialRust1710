# F51–60: 管理・認証・セキュリティ 段階実装

このブランチの実装状況。CIとJava 1.7.10実クライアントによる動作確認に合格するまでは公開用途に使わないこと。

## 認証の境界

Minecraft Java 1.7.10 Protocol 5 は現在も offline-mode のみ。アカウント名・offline UUIDは認証済みの識別子ではない。server.properties の online-mode=true は明示的にエラー終了する。Mojang sessionserver (hasJoined)の照合とRSA/AES CFB8暗号化が実装・検証されるまで解除しない。

ops.json に名前を載せてもオフラインプレイヤーにゲーム内管理権限を付与しない。OSコンソール専用。LAN公開の --insecure-offline-lan は引き続き危険な運用モード。

## コンソール

- /list, /save, /time query daytime, /time set 6000, /weather query, /weather set clear, /tp Player 1 65 1
- /op Player, /deop Player, /ban Player reason, /pardon Player, /ban-ip 192.0.2.1 reason, /pardon-ip 192.0.2.1
- /kick Player reason, /whitelist reload, /whitelist list, /permission Player chat|build|interact allow|deny

起動時に管理JSONがなければ空配列で新規作成する。各JSONが不正・重複・非通常ファイルの場合は拒否する。ログイン時/セッション中はBANやホワイトリストが壊れると安全側で切断する。

## 手動試験項目

1. 無改造Java 1.7.10でログイン。一般プレイヤーの/saveは禁止、/listは可能。
2. /ban・/pardon・/ban-ip・/pardon-ipの反映と再起動後保持。
3. /kickの理由表示・セッション切断・最終保存。
4. IPv6とIPv4-mapped IPv6のBAN、1 IP接続枠超過・再接続回数制限。
5. チャット大量送信・異常文字列、permission反映、破損JSONのFail Closed。
6. admin-audit.jsonlのattempt/success/failureと監査I/O障害時の操作拒否。
