# E41–E50 品質改善追補（2026-10-21）

## このブランチでの実装

本変更は E グループの**追加レビュー可能な差分**です。E41〜E50 の全機能が完成したという意味ではありません。既存のドラフト PR #61 → #69 → #73 に対する機能重複を避け、`main` 上の検証器を強化しています。

| ID | 追加した内容 | 受入可能な範囲 |
| --- | --- | --- |
| E41 / E50 | Protocol 5 の `BufferedFrameReader` で、最大サイズのフレーム直後に次のフレームが連続しても、受信読み過ぎに起因する上限誤判定を避ける | 合成 TCP 入力によるユニットテスト。Java GUI 実機試験ではない |
| E47 / E50 | 1.7.10 TileEntity NBT の検証で、所有チャンクの座標、同一位置の重複、バニラ容器のSlot範囲を確認 | 読み取り専用 Anvil Inspector の安全性向上。ライブ保存ではない |

### TileEntity が使う検証範囲

- Chest: 0..26
- Trap / Dispenser / Dropper: 0..8
- Furnace: 0..2
- Hopper: 0..4
- BrewingStand: 0..3
- 未知の TileEntity ID: 互換性を損なわないようバニラのスロット数は**強制しない**。既存の総数、重複、ItemStack数値の検証は継続。
- x/z のチャンク境界は `div_euclid(16)` で扱う。例えば x=-1 はチャンク -1、x=0 はチャンク 0。

### 検証方法

```bash
cargo fmt --all -- --check
cargo test --workspace --all-targets
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release -p vanilla-server -p legacy-status-server
```

特に `tile_position_and_vanilla_container_slot_bounds`、`chunk_tile_entities_must_belong_to_the_enclosing_column`、`max_size_frame_followed_by_small_frame_does_not_false_overflow` のテストを追加しました。

### 運用上の安全条件

- Anvil 本家ワールドを誤ってIRWファイルに変換・上書きしない既存制約を維持する。
- セーブ形式の有効化前に、停電/強制終了での再実行・未知NBTタグの保持・跨ぎファイル整合性を検証する。
- Rust TCP疑似クライアントのテスト成功と、本家 Java 1.7.10 GUI 実機試験の成功は**区別**する。
- E45 のジャーナルPRと E46 本保存を順序なしに統合しない。保存が2重化・分離する危険がある。
