## 実装内容

- **D39 / P0**: 死亡時の所持品回収が window 0 の防具スロット 5〜8 を二重列挙し、防具を複製する不具合を修正。クラフト2×2、装備、防具、バックパック、ホットバー、3×3、カーソルの各スロットを一度だけ列挙する。`clear_possessions()` と同じ対象範囲に統一し、ドラッグ操作の一時状態もクリア。既存の journal 付き死亡ドロップコミットを維持。
- **D37 / P0**: 1.7.10 のキノコシチュー（6、隠し満腹度 7.2）、腐肉（4、0.8）、クモの目（2、3.2）、青くなったジャガイモ（2、1.2）の基本栄養値を追加。キノコシチュー飲食時には空ボウルを**同じ確定予定インベントリ**に払い戻す。満腹度反映とアイテム減算の順序は既存の安全側処理を維持。
- **D38 / P1**: 1.7.10 防具の素材・部位別耐久値を追加。Mob/爆発の防具で軽減可能な攻撃時のみ、各装備に最低1・原ダメージ4点あたり1の耐久損耗を適用。耐久切れで装備を外し、保存・Protocol 5 inventory同期する。落下・飢餓・毒では損耗させない。エンチャント耐久補正は未対応。
- **D34 / P1**: 再生・毒の周期をエフェクト強度に応じて短縮（基本50/25tickをアンプで右シフト、下限1tick）。死亡中の再生を禁止し、リスポーン時の一時効果を破棄。
