# D31–D40 継続実装: クラフト拡張と死亡XP位置の整合（2026-10-21）

## 背景・重複回避

Dグループ既存PR #67 → #76 → #79 は main に統合済み。別途 #54 は同じ機能の旧Draftが存在するため、そのコードを丸ごと二重実装しない。本変更は最新mainから独立させ、D33 のバニラレシピ拡充、D32 のアイテム増減防止テスト、D39 の死亡場所におけるXPドロップ修正に限定する。

## 変更内容

- **D33**: 1.7.10 の基本レシピを追加: 木・石ボタン、石/重み付き感圧板、骨粉、ブレイズパウダー、ボウル、はしご、看板、トリップワイヤーフック、ジャック・オ・ランタン、粘土/レンガ/雪/グロウストーン/ネザーレンガ/クォーツブロック、絵画、額縁、釣り竿、TNT、金リンゴ2種、きらめくスイカ、キノコシチュー、発酵したクモの目、マグマクリーム、チェスト/かまど/TNT/ホッパー付きトロッコ。
- **D32/D33**: 3個出力の看板をShift連続クラフトした際、空きが足りなければ素材を減らさず、不足分のみの不正生成をしない回帰テストを追加。16個上限の看板で確認。
- **D39**: 死亡地点を退避した後にベッドへリスポーンさせる。XPオーブの配置には退避した死亡座標を使用し、ベッド座標を誤使用しない。
