# グループD（D31–D40）追補: 2026-10-21

## 位置づけ

本ブランチは PR #67 → #76 の上に積む追補です。すでに存在する D31–40 の基盤を置き換えず、サーバ権威の在庫制約と走行消耗を追加します。**D31–D40 の全機能完成を表しません。**

## 今回の変更

- **D31/D40**: かまどの Shift 燃料投入で一律64個を前提にせず、Stack::max_count() を使用。溶岩バケツなどの非スタック燃料が2個に増える不正状態を防止するテストを追加。
- **D32/D40**: 醸造台（4スロット）の 0–2 はポーション瓶のみ、3 は醸造材料のみという制限を、通常クリック・Shift移動・ドラッグ・保存データの検査で共有。拒否時に所持アイテムが消えないことをテスト。
- **D37**: Protocol 5 の Entity Action 0x0B（VarInt Entity ID / Action / Jump Boost）の Sprint start(3)/stop(4) をサーバで処理し、通常移動とスプリント移動に異なる exhaustion を適用。空腹度6以下で新規Sprint開始不可。異常距離/NANを拒否するテストを追加。
