# D34 / D37: Java 1.7.10 食事による状態異常・飢餓ダメージ (2026-10-21)

## 今回の実装

- 生鶏肉 30% Hunger I (600 tick)、腐肉 80% Hunger I (600 tick)
- クモの目で Poison I (100 tick)、青くなったジャガイモ 60% Poison I (100 tick)
- フグで Hunger III (300 tick)、Poison IV (1200 tick)、Nausea II (300 tick)
- 食物を実際に消費し、インベントリおよび満腹度保存が成功してから状態異常を付与
- クライアント提示確率を信用せず、サーバーの tick と entity ID を混合して0〜99の疑似乱数サンプルを計算
- Hunger は毎tick 0.005 × (amplifier+1) の exhaustion を追加。効果中の隠し状態保存は最大毎秒1回とし、可視状態変更時にHealth Updateを送信
- 食事の弱い・短い効果は既存の強い・長い同種ポーション効果を上書きしない
- 飢餓によるダメージ下限: Peaceful=無効 / Easy=10 HP / Normal=1 HP / Hard=0 HP。現在のサーバーはNormal固定なのでJoin Game/Respawnの難易度バイトを2へ統一
