# Minecraft 1.7.10 Rustバニラ最小サーバー（開発版）

## 目的

Mod JAR/Forge/FML/Configは扱わず、バニラ1.7.10（Protocol 5）用のRustネイティブサーバーを単独で動かす。

## 起動

~~~bash
cargo run --release -p vanilla-server -- --bind 127.0.0.1:25565 --world ./world/flat.irw
~~~

初期待受は127.0.0.1のみ。LANの実験では --bind 0.0.0.0:25565 と指定可能だが、**Microsoft/Mojangのユーザー認証なしのoffline-mode**。インターネット公開してはいけない。1プレイヤーのみ。Minecraftの実ワールド保存先を指定しないこと。

## 今回の対応範囲

- Handshake、Status/Ping、Login Start、名前検査、offline UUID、Login Success。
- Play: Join Game、Creative、Spawn、Health、Player Abilities、Time、Position/Look。
- 5×5チャンク（80×80）の固定平坦地形と1.7.10のzlib圧縮Chunk Data。
- 移動パケット、KeepAlive、チャット、/help、/save。
- Creativeでの限定的な通常ブロックの設置・破壊、更新送信、距離・座標検証。
- 変更ブロックの独自IRW1セーブ形式（サイズ制限、簡易破損検出、保存失敗時ロールバック）。

## 未対応

- Mod/Forge/FML、正式な20TPSゲームループ、Mob/AI、サバイバル、インベントリ/クラフト、物理・光源更新、レッドストーン、複数プレイヤー。
- NBT/Anvilの読み書き、既存Minecraftワールドとの互換、ワールドの動的拡張。
- 公開用のオンライン認証/セキュリティ/権限管理。実機Minecraft GUI接続は別途確認が必要。

現段階の完成判定はRust単体テストと独立したProtocol 5ソケットテストが通ること。Playパケットを送れる状態と「完全にMinecraftを遊べる」は別。

## テスト

~~~bash
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo run -p vanilla-server -- --bind 127.0.0.1:25568 --world ./world/smoke.irw
# 別ターミナル
python3 tests/vanilla_smoke.py 127.0.0.1 25568 ./world/smoke.irw
~~~

Protocol 5参考資料: PrismarineJS minecraft-data /protocol/pc/1.7 と Forge 10.13.4.1614の公開ドキュメント。クライアントはバニラ1.7.10に限定。
