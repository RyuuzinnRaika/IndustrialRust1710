# E49 先行統合: 永続時計・管理コンソール (2026-10-22)

この変更は既存Draft #87の時計部分を現行mainへ移植したもので、E49/E50全機能の完成を示すものではありません。

- 時計ファイルをIRT1（20バイト）からIRT2（37バイト）に移行。IRT1を読み込めて、再保存時はIRT2に移行する。
- Tick、日照時刻のoffset、天候overrideを補数検証付きで保存する。破損ファイルは起動時エラーとして拒否する。
- OSの標準入力（サーバーコンソール）だけから次のコマンドを使用可能。
  - `/time query daytime`
  - `/time set 0..23999`
  - `/weather query`
  - `/weather set auto|clear|rain|thunder`
- 更新をすぐ保存してProtocol 5のTime Update / Change Game Stateを接続クライアントへ通知する。
- 無認証のゲーム内チャットから管理操作は行えない。
- 既存20TPSのtickと保存・天候処理を引き続き共有する。

**残件:** Draft #87のセッション所有テレポート(`/tp`)は今回含めていない。旧NBT完全互換、実クライアントGUI接続試験、8人長時間負荷試験は別途必要。
