# E49 管理コンソール・セッション所有テレポート先行統合

Draft #87のテレポート機能のみ現行mainへ移植する（時計と天候は #114 に統合済み）。

- OS標準入力からの `/tp PLAYER X Y Z` のみを管理操作とし、ゲーム内チャットからは管理権限を与えない。
- Hubの名前検索は大文字小文字を区別せず、オフラインの対象は拒否。NaN・無限大・範囲外座標は拒否。
- 対象セッションの有界キューへ内部専用イベントを入れる。Protocol 5ネットワークパケットとして送信しない。
- セッション自身がプレイヤー位置を永続化後、チャンク同期、S08位置通知、他プレイヤー向け位置同期を行う。
- 移動後の落下・採掘・食事・弓状態をリセットしてセッション内の旧位置処理を持ち越さない。

検証: Rust formatting / unit and TCP integration tests / Clippy / release build。無改造Java 1.7.10 GUI操作と長時間負荷検証は別途必要。
