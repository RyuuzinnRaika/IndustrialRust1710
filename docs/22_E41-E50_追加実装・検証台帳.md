# E41–E50 グループ E 追加実装・検証台帳（2026-10-21）

本ブランチは **PR #61 → PR #69 の上に積む incremental PR**。既存ブランチの変更を直接上書きせず、追加の安全性・計測品質・Golden Test のみに絞る。10項目すべての完成を意味しない。

## 変更内容と検証可能な範囲

- **E41 / E50**: Protocol 5 の Set Slot (S2F)、Window Items (S30)、Cursor の固定バイト列と、サーバ本体が生成した inventory の実バイト列を対照するユニットテストを追加。TCPフレームの各2分割境界とタイムアウトを総当り検証。
- **E43 / E50**: プレイヤーの視界判定に NaN / ±Infinity / i32範囲外の座標が入っても、i32の差分・absオーバーフロー、異常なentity表示が起きないよう拒否する。負座標と正負の広域座標を回帰テストで固定。
- **E44**: 圧縮キューが瞬間的に満杯になった場合はrawチャンクを保持して、セッションスレッドに限り最大100msまで短時間再投入する。ワールドmutexは待機時に保持しない。生成/読込/送信の完全非同期化・公平リトライは未完。
- **E49**: OS標準入力にローカル管理コンソールを接続。/list、/time query daytime、/weather query、および/whitelist list/add/removeを用意。ホワイトリストのUUIDメタデータを維持して同期保存し、プレイヤー名を管理権限として使わない。
- **E48**: `metrics-summary` を拡張。窓別の `mspt_mean` と `mspt_samples` からサンプル重み付き全体平均を算出。プレイヤー人数ごとに有効TPS・Tick配信率・最悪P99 MSPT・計測窓時間をグループ化。測定時間不足を検出できる `--min-seconds` と `--min-windows` を追加。P95>P99、8人上限を超える架空負荷、4096件を超えるサンプル等は不正データとして拒否。
- 互換性のため、旧テレメトリ行に `mspt_samples` が無いときは重み付き平均計算の対象外（null/0を表示）にする。

## 実行手順

```sh
cargo fmt --all -- --check
cargo test --workspace --all-targets
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release -p vanilla-server

cargo run --release -p vanilla-server --bin metrics-summary -- \
  world/flat.metrics.jsonl \
  --min-seconds 1800 --min-windows 100 \
  --min-tps 19.0 --min-tick-ratio 0.95 \
  --max-p99-mspt 50 --max-rss-mib 512
```

指定しきい値は受入基準として決定したものではなくサンプル。通常world workerの10秒テレメトリで30分以上を想定した例。指標の計測値を作り物で埋めない。

## 実機試験と運用注意

- 無改造 Java 1.7.10 クライアントと Rust テストクライアントは同一視しない。サーバ内テストが成功しても E42 の完了ではない。
- 性能計測はワールド、CPU、IO、描画距離、接続プレイヤー数・操作負荷を固定して比較する。
- クラッシュ試験はバックアップしたテストワールドを使う。ワールドファイル等のジャーナル回復は起動前に実行し、壊れたジャーナルを無視して起動しない。
- このサーバは offline-mode でありアカウントの所有者確認を行わない。プレイヤー名を OP 権限根拠にしない。信頼できないインターネットへ公開しない。
- **PR #61、#69を順番にレビュー統合し、本PRのCI成功を確認してから最終的にbaseを main に付け替える。**
