## 共通データ契約と禁止すべき版混同

1. 同一Entityには一意なEntity ID、位置、HP、速度、状態、Dimension、Owner/Attacker情報を持たせる。Spawn/Move/Destroyの相対順序と保存を一致させる。
2. アイテムの数は全所有者を合算して保存される：`Player + Container + Cursor + Ground + InFlightTransfer + 合法Drop`。正当なCraft/Smelt/Consumeは入力と出力のレシピで量保存を検証する。
3. 1.7.10には1.9のオフハンド/盾/長い攻撃クールダウンはない。1.7.10の戦闘tick・無敵tick・武器特性を参照し、現代仕様を転記しない。
4. 1.7.10の醸造台は**3瓶+1材料（燃料欄なし）**。ブレイズパウダーを燃料とする変更は1.9由来であり禁止。
5. 1.7.10のエンチャント台に1.8のラピス要求を導入しない。GUI・表示レベル・消費レベルは当時の仕様と一致させる。
6. 1.7.10に存在しない`/fill` / `/clone` / `/execute` / `/worldborder` / `/title`を必須コマンド一覧に混入させない。
7. チャンク/Player/Container保存では、古い世代を新しい世代と混同しない。未知ID/NBTは無断で削除・初期化しない。
8. Windows GUIを含む製品/運用ロジックはRustのみ。既存の非Rust機能は移行負債として追跡し、実装済と偽らない。
