## 1. ゴールと必ず守る原則

**最終ゴール:** 無改造Java 1.7.10クライアントから接続し、複数人で新規サバイバルワールドの採掘・クラフト・食事・戦闘・探索・設備利用・死亡・再接続・保存復旧を続けても、不自然な位置巻き戻し・操作不能・データ消失・複製・クラッシュが起きず、本家1.7.10の挙動と一致する。

**マイルストーン**
- **M0 / P0**: Windows/Linux起動、Protocol 5接続、名前/認証/権限、チャンク送信、移動同期、停止・再起動・保存の安定。
- **M1-min / P0（最優先）**: [#665](https://github.com/RyuuzinnRaika/IndustrialRust1710/issues/665) S00–S09を**同じ新規Survivalワールドで連続PASS**。「木→石→鉄→食事→Mob→死亡→保存」が抜けなく機能。
- **M1 / P1**: 全ブロック/主要GUI/アイテム・Mob・農業/睡眠などサバイバル全系統を充足し、2人で継続プレイ。
- **M2 / P1**: 1.7.10 GenLayer、全樹種、構造物、照明、レッドストーン、TNT、Nether/End、ワールド生成・ブロック物理の互換。
- **M3 / P0**: ジャーナル、Anvil移行、認証・管理・バックアップ、故障時復旧、各種データ保存の保証。
- **M4 / P1**: 無改造1.7.10クライアントの多人数・負荷・長時間受入と差分解消。[#20](https://github.com/RyuuzinnRaika/IndustrialRust1710/issues/20)で完成判定。

**完了の解釈:** コードが存在 / 部分動作 / RustテストPASS / Windows動作PASS / 無改造Minecraft 1.7.10実機PASS / 再起動・クラッシュ復旧PASSは別の状態。テスト未実施、PR未マージ、古いIssueの報告を「完成」に変換しない。実装済み機能でも、下記の受入条件が未確認なら「要受入」のまま。

## 3. バージョン境界・外部仕様

1. 1.7.10は2014-06-26リリース、**Protocol 5**。1.7.2で入った新バイオーム・アカシア・ダークオーク・釣りの新要素は対象。
2. 1.8で加わったウサギ、ガーディアン、海底神殿、花崗岩/閃緑岩/安山岩、スライムブロック、旗、アーマースタンド等は対象外。1.8追加の `/fill`, `/execute`, `/clone`, `/title`, `/worldborder` も対象外。
3. 1.7.10特有の数値ID・Damage/metadata・NBT・エンティティID・パケット/ディメンション遷移を互換対象とする。新バージョンのブロックステート、レシピJSON、Brigadier、オフハンド等を採用しない。
4. 樹木は**オーク・マツ（トウヒ）・シラカバ・ジャングル・アカシア・ダークオーク**の6樹種と1.7.10当時の形状差（大木・2×2大型トウヒ/ジャングル、2×2必須ダークオーク、アカシアの枝）を対象とする。
5. Wikiは仕様の参照資料。各仕様は必要ならJava 1.7.10の実機観測・保存NBT・パケット記録・固定seed goldenで裏付ける。推測で数値を埋めない。

**Wiki起点:** [1.7.10](https://minecraft.wiki/w/Java_Edition_1.7.10) / [1.7.2](https://minecraft.wiki/w/Java_Edition_1.7.2) / [1.8との差分](https://minecraft.wiki/w/Java_Edition_1.8) / [ブロック履歴](https://minecraft.wiki/w/Block) / [コマンド履歴](https://minecraft.wiki/w/Commands) / [樹木](https://minecraft.wiki/w/Tree) / [バイオーム](https://minecraft.wiki/w/Biome) / [Mob](https://minecraft.wiki/w/Mob) / [Anvil](https://minecraft.wiki/w/Anvil_file_format) / [サーバー](https://minecraft.wiki/w/Server)。

- Tab補完はC14→S3Aで候補生成。権限のない命令/ユーザー/引数を不適切に出さず、**補完リストは認可判定を代替しない**。
- 現行機能の一部が `docs/34_1_7_10_commands.md` と [#649](https://github.com/RyuuzinnRaika/IndustrialRust1710/issues/649) に存在。**全コマンドは実機合格前には部分実装扱い**。
